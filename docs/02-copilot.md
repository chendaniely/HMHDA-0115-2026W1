# 2. Sign up for GitHub Copilot

GitHub Copilot is an AI assistant built into VS Code. It is already installed in your Codespace,
and it works once your GitHub account has a Copilot plan.

## Everyone: turn on Copilot Free

Copilot Free works with any personal GitHub account and costs nothing. It has monthly limits:
2,000 code suggestions a month and a smaller allowance for chat, and it chooses the AI model for
you.

1. Sign in to GitHub.
2. Open <https://github.com/copilot> and follow the prompts to start using Copilot Free.
3. To check what your account has, open <https://github.com/settings/copilot/features>.

You never need to enter payment details for this course. If GitHub asks for them, stop and
contact the teaching team.

## If you are also a student in a degree or diploma program

Verified students can get **Copilot Student** for free, which has more than Copilot Free. You
qualify only if you are enrolled in a degree- or diploma-granting program, such as a college or
university. If you are not sure, use Copilot Free.

1. Sign in to GitHub.
2. Add your school email address to your GitHub account, and verify it.
3. Have proof of your current student status ready, in case GitHub asks for it.
4. Apply at <https://education.github.com/pack>.

You don't have to wait for approval. Use Copilot Free while your application is pending.

## Check Copilot in your Codespace

Do this after you [open your Codespace](03-open-codespace.md).

1. Click the **Extensions** icon in the left sidebar (it looks like four squares).
2. Check that **GitHub Copilot Chat** and **R** are both installed.
3. Open the Chat: click **View → Command Palette**, type `chat`, and click **Chat: Open Chat**.
   You can also click the chat icon at the top of the VS Code window.
4. If the Chat asks you to sign in, follow its prompts with the same GitHub account.

⚠️ Never paste real patient data or other private information into the Chat. And check
everything it tells you: AI answers can be wrong.
